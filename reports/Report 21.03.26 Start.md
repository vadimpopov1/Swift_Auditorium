## Исследование возможностей iOS для передачи информации о студентах.

- Изначальная задумка проекта с передачей данных о студенте по NFC оказалась практически невозможной или слишком неудобной. Для использования NFC с последними версиями ОС (iOS 16+) требуется "посредник" через который будет происходить запись данных, а уже с неё преподаватель сможет считать (Единственный 100% рабочий метод, который неудобен). После изучения множества форумов было обнаружено что большая часть чипов для чтения/записи на Android устройствах не поддерживаются на стороне Apple, поэтому единственный выход - поиск альтернативы. Остатется вариант с эмуляцией NFC метки на Android, но требует дополнительного изучения.
  
- В качестве альтернативы - передача метрик через QR-коды. Для этого потребуется хранение данных о студенте, генерация уникального QR и его показ преподавателю (суперюзеру). В качестве тестового решения изучил библиотеку CoreImage для генерации. Написал простую функцию, которая приводит https-ссылку в QR-код для сканирования.
