# Отчёт о проделанной работе
**Дата сдачи:** 02.05.2026  

## Описание проделанной работы
Изменена панель регистрация. Теперь требуется код приглашения для регистрации содержащий хеш информацию.

## Реализация авторизации студента
- Изменен экран регистрации с дополнительными проверками.
- Изучил возможноости Swift UI и реализовал простую анимацию в качестве эксперемента.
- Исправлены прочие баги (Авторизация под преподавателем с аккаунта студента и наоборот и т.п.).

## Отображение профиля пользователя
- После успешного входа сервер возвращает `token`, `role`, `user_ID` и `login`.
- На главном экране добавлена карточка профиля: логин, роль («Преподаватель» / «Студент») с иконкой и числовой ID пользователя.
- Иконка и цвет аватарки в карточке зависят от роли (синий - преподаватель, зелёный - студент).

## Выход из аккаунта
- В карточке профиля добавлена кнопка выхода.
- При нажатии появляется системный диалог подтверждения после подтверждения JWT-токен сбрасывается и пользователь возвращается на экран входа.
