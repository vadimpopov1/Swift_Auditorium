# Отчёт о проделанной работе
**Дата сдачи:** 15.05.2026  

## Описание проделанной работы
Добавил раздел с созданием занятия, генерации пригласительного QR и отметкой посещаемости со стороны студента.

## Экран преподавателя
- Добавлен раздел создать сессию с выбором времени действия.
- После создания сесии появляется новая плитка с краткой информацией:
    1. Название занятия
    2. Количество студентов в группе для которой создана сессия
    3. Остсток действия QR'а.
- Плитка статистики группы, где будет отображено занятие и количество присутствующих студентов.

## Экран студента
- Перенесена кнопка на центр
- Изменен запрос, который перенаправляет студента для отметки посещаемости с дополнительными данными.
